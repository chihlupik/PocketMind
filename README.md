# 🤖 PocketMind — Карманный ИИ-помощник и Терминал для Android

**PocketMind** — это офлайн-приложение для Android, которое объединяет локальную нейросеть (Qwen 2.5 0.5B через `llama.cpp`) и мощный терминал для выполнения системных команд прямо со смартфона.

Никаких серверов, интернета для работы ИИ и слива данных — **всё работает полностью локально в памяти вашего телефона!**

---

## 🌟 Главные фишки проекта

- 🔒 **100% Конфиденциальность:** Нейросеть запускается прямо на процессоре вашего устройства.
- ⚡ **Прямые команды:** Выполнение системных утилит (`exec`, `run`, `cat`, `cd`, `ls`, `mkdir`, `rm`) без лишних посредников.
- 📜 **Автоматизация:** Запуск `.sh` скриптов прямо из чата.
- 🧠 **Кастомные навыки:** Обучение ИИ новым командам прямо на лету (`learn skill`).
- 📥 **Автозагрузка модели:** При первой сборке проект сам скачает файл весов нейросети через интернет.

---

## 🛠️ Что нужно установить на компьютер перед началом

Чтобы успешно собрать проект из исходников, вам понадобятся:
1. **Android Studio** (скачайте и установите с официального сайта).
2. **Android NDK** и **CMake** (специальные инструменты для сборки C++ кода, которые требует движок ИИ).

---

## ⚙️ Установка NDK и CMake через терминал

Если вы запускаете проект впервые, вам нужно скачать NDK и CMake. Выберите вашу операционную систему и выполните команду:

### 🪟 Windows (PowerShell)
1. Нажмите клавиши **Win + X** и выберите **PowerShell** (или *Терминал*).
2. Выполните команду:
   `$env:LocalAppData\Android\Sdk\cmdline-tools\latest\bin\sdkmanager.bat "ndk;26.1.10909125" "cmake;3.22.1"`

---

### 🍎 macOS (Terminal)
1. Нажмите **Cmd + Пробел**, введите **Terminal** и нажмите Enter.
2. Выполните команду:
   `~/Library/Android/sdk/cmdline-tools/latest/bin/sdkmanager "ndk;26.1.10909125" "cmake;3.22.1"`

---

### 🐧 Linux (Terminal)
1. Откройте терминал (нажмите **Ctrl + Alt + T**).
2. Выполните команду:
   `~/Android/Sdk/cmdline-tools/latest/bin/sdkmanager "ndk;26.1.10909125" "cmake;3.22.1"`

---

> 💡 **Самый легкий способ без терминала:**
> Откройте Android Studio ➔ `Tools` ➔ `SDK Manager` ➔ вкладка `SDK Tools` ➔ отметьте **NDK (Side by side)** и **CMake** ➔ нажмите **Apply**.

## 📦 Как склонировать и запустить проект

1. **Скачайте исходный код к себе на компьютер:**
   Выполните в терминале:
   `git clone https://github.com/YOUR_USERNAME/PocketMind.git`

2. **Откройте проект в Android Studio:**
   Запустите Android Studio, нажмите `File` ➔ `Open` и выберите папку с проектом.

3. **Синхронизируйте проект с Gradle:**
   Нажмите на иконку маленького слоника 🐘 в правом верхнем углу интерфейса (**Sync Project with Gradle Files**) и подождите пару минут.

4. **Запустите приложение на телефоне или эмуляторе:**
   Подключите свой Android-смартфон по кабелю (включив *Отладку по USB*) и нажмите зеленую кнопку ▶️ (**Run**).

> ℹ️ **Важно:** При первой сборке проект автоматически скачает файл ИИ-модели (`qwen2.5-0.5b-instruct-q4_k_m.gguf`) через `curl` в папку `src/main/assets/`. Больше ничего вручную скачивать не нужно!

## 💻 Шпаргалка по командам внутри приложения

- **`exec <команда>`** — Выполнить любую системную команду (Пример: `exec echo "Привет"`)
- **`run <файл.sh>`** — Запустить ваш готовый bash-скрипт (Пример: `run test.sh`)
- **`cd <путь>`** — Переключиться в другую папку (Пример: `cd /storage/emulated/0/Download`)
- **`ls`** — Показать список файлов в текущей папке
- **`pwd`** — Показать текущий рабочий путь
- **`cat <файл>`** — Прочитать текст из файла (Пример: `cat config.txt`)
- **`mkdir <имя>`** — Создать новую папку (Пример: `mkdir MyFolder`)
- **`rm <объект>`** — Удалить файл или папку (Пример: `rm file.txt`)
- **`learn skill`** — Научить ИИ новому сокращению (Пример: `learn skill hi = exec echo Hello`)
- **`list skills`** — Показать список сохраненных навыков
